## بازتولید

با Python 3.10 و نسخه‌های ثبت‌شده در فایل وابستگی‌ها اجرا شده است. فرمان‌ها را از همین پوشه اجرا کنید.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
mkdir -p data/raw
curl -fL https://d37ci6vzurychx.cloudfront.net/trip-data/yellow_tripdata_2024-01.parquet -o data/raw/yellow_tripdata_2024-01.parquet
curl -fL https://d37ci6vzurychx.cloudfront.net/misc/taxi_zone_lookup.csv -o data/raw/taxi_zone_lookup.csv
python src/phase2.py
python src/build_report.py
jupyter nbconvert --to notebook --execute --inplace notebooks/phase2_preparation.ipynb
```

اگر فایل‌های خام در مخزن فاز یک موجودند، برای ساخت خروجی‌ها از `python src/phase2.py --raw-dir ../data/raw` استفاده کنید. منبع، اثرانگشت فایل‌ها و شرح جدول‌ها در [راهنمای داده](data/README.md) آمده است. برای مرور گزارش و نوت‌بوکِ دارای خروجی، نیازی به دانلود داده نیست.

## دامنهٔ تحلیل

آموزش ۱ تا ۲۱ ژانویه، اعتبارسنجی ۲۲ تا ۲۸ ژانویه، و آزمون ۲۹ تا ۳۱ ژانویه است. همهٔ مرزها به وقت محلی نیویورک و در ابتدای روز هستند. خروجی آزمون برای نگهداری برچسب و ویژگی‌های فاز بعد ساخته شده و در انتخاب خوشه، PCA یا کالیبراسیون ناهنجاری شرکت ندارد. فاز دو هیچ معیار عملکردی برای مدل پیش‌بینی گزارش نمی‌کند.
