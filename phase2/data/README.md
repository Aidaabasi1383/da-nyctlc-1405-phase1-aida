# داده‌های فاز دو

دو ورودی رسمی کمیسیون تاکسی و لیموزین نیویورک در مسیر محلی `data/raw/` قرار می‌گیرند. فرمان دریافت در [راهنمای فاز دو](../README.md) آمده است.

- `yellow_tripdata_2024-01.parquet` شامل رکوردهای سفر تاکسی زرد ژانویهٔ ۲۰۲۴ است.
- `taxi_zone_lookup.csv` شناسهٔ مناطق را به نام منطقه، بخش شهر و نوع ناحیهٔ خدمات نگاشت می‌کند.
- زمان‌های فایل سفر به وقت محلی نیویورک خوانده می‌شوند. ماه ژانویه شامل تغییر ساعت تابستانی نیست. [منبع رسمی داده](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page)

خروجی `processed/summary.json` اثرانگشت SHA-256 دو فایلِ استفاده‌شده را دارد. دادهٔ خام حجیم در بسته نیست. جدول‌ها شمارش و بازنمایی تجمیعی‌اند.

| فایل یا گروه | واحد هر سطر |
|---|---|
| `hourly_features.csv` | یک ساعت تقویمی و شمار سفر ثبت‌شده پس از پالایش |
| `split_summary.csv` | یک بخش زمانی به همراه تعداد ساعت، سفر و ساعات با تاریخچهٔ کامل |
| `cleaning_funnel.csv` و `missingness.csv` | یک قاعدهٔ پالایش یا یک فیلد ممیزی |
| `training_borough_od.csv` | یک جفت بخش شهر مبدأ–مقصد در آموزش با حداقل ۲۰ سفر |
| `zone_profiles.csv` و `zone_clusters.csv` | یک منطقهٔ مبدأ، به‌ترتیب واجد شرایط و همهٔ مناطق پنج بخش |
| `cluster_centroids.csv`، `cluster_summary.csv` و `cluster_borough_mix.csv` | یک خوشه با توزیع ساعتی، حجم یا شمار منطقه به تفکیک بخش |
| `cluster_selection.csv` و `cluster_stability.csv` | یک مقدار k یا یک اجرای سنجش پایداری |
| `pca_variance.csv` و `pca_loadings.csv` | یک مؤلفه یا بار دو مؤلفهٔ نخست برای یک ساعت |
| `demand_anomalies.csv` | یک ساعت نامزد ناهنجاری در آموزش یا اعتبارسنجی |
| `raw_anomaly_flags.csv` | شمار تجمیعی یک پرچم کیفیت یا کرایهٔ غیرمعمول با امکان همپوشانی |

در جدول‌های پروفایل، مرکز خوشه و بار PCA، ستون‌های عددی ساعت را نشان می‌دهند. ستون‌های سهم به صورت کسری از یک ذخیره شده‌اند. جای خالی وقفه‌ها یعنی تاریخچهٔ موردنیاز پیش از آغاز ژانویه قرار دارد. شناسهٔ ۲۶۴/۲۶۵ یا نگاشت نامعتبر در تجمیع بخش شهر در گروه `Unknown` است. فرودگاه نیوآرک در `EWR` نگهداری می‌شود و در خوشه‌بندی مناطق پنج بخش وارد نمی‌شود. جدول ساعتی مانند فاز یک همهٔ رکوردهای پالایش‌شدهٔ فایل را می‌شمارد، از جمله رکوردهای دارای مبدأ نامعلوم یا نیوآرک.
